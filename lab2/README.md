# Лабораторная работа № 2. Пункт 1

`NumberTheory` в `number_theory.hpp` и `number_theory.cpp` предоставляет статические методы для вычислений в целых числах. У класса нет полей. Каждый вызов работает только со своими аргументами. `main.cpp` демонстрирует все операции.

## Сборка в WSL

Для C++17 нужны заголовки Boost.Multiprecision, например из пакета `libboost-dev` в Ubuntu. Boost используется для арифметики длинных целых и вещественных чисел. Алгоритмы задания реализованы в `number_theory.cpp`.

Из корня проекта:

```sh
g++ -std=c++17 -O2 -Wall -Wextra -Wpedantic lab2/main.cpp lab2/number_theory.cpp -o /tmp/mai-lab2
/tmp/mai-lab2
```

## Операции

| Метод | Как работает |
| --- | --- |
| `gcd` | Алгоритм Евклида заменяет пару на делитель и остаток, пока остаток не станет нулём. |
| `extendedGcd` | Для каждого остатка сохраняет его коэффициенты при исходных аргументах. Возвращает `gcd`, `x`, `y` для равенства `a*x + b*y = gcd(a,b)`. |
| `binaryGcd` | Алгоритм Штейна использует сдвиги для удаления множителей 2 и вычитает меньшую нечётную часть из большей. |
| `modPow` | Возведение в квадрат и умножение по битам неотрицательной степени с промежуточным взятием по положительному модулю. |
| `legendre` | Критерий Эйлера. По контракту знаменатель является нечётным простым числом. Вызывающий код отвечает за его простоту. |
| `jacobi` | Удаление множителей 2 и закон квадратичной взаимности для положительного нечётного знаменателя. При составном знаменателе результат +1 сам по себе не устанавливает, что числитель является квадратичным вычетом. |
| `phiByDefinition` | Подсчёт чисел от 1 до n, взаимно простых с n. |
| `phiByFactorization` | Произведение значений p^(e−1)(p−1) по степеням простых в разложении n. |
| `phiByFourier` | Сумма gcd(k,n)·cos(2πk/n) по k от 1 до n с округлением результата до целого. |
| `carmichael` | НОК значений λ для степеней простых. Для степени двойки 2^e при e ≥ 3 значение равно 2^(e−2). Для остальных степеней используется φ. |

НОД неотрицателен, в том числе для отрицательных аргументов. Принято `gcd(0,0) = 0` и `φ(1) = λ(1) = 1`.

Подсчёт по определению и формула Фурье перебирают все числа от 1 до n. Варианты с разложением используют пробное деление. Эти методы подходят для демонстрации на небольших n. В формуле Фурье косинусы вычисляются приближённо с 50 десятичными разрядами. Точные расчёты дают методы `phiByDefinition` и `phiByFactorization`.
