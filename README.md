# Лабораторная работа № 1 по основам криптографии

Реализация на C++17 разделена между `crypto.hpp`, `des.cpp`, `deal.cpp` и `lab1.cpp`. Готовые криптографические библиотеки не используются.

## Сборка и запуск

```sh
g++ -std=c++17 -O2 -pthread lab1.cpp des.cpp deal.cpp -o lab1
./lab1 --self-test
./lab1
```

`--self-test` проверяет известный DES-вектор, обратимость DEAL для всех трёх длин ключа и обратное преобразование во всех режимах, набивках и нескольких граничных длинах. Запуск без параметров демонстрирует обратное преобразование 256 псевдослучайных байтов для DES и DEAL во всех режимах.

## Шифрование и расшифрование файлов

Общий формат:

```sh
./lab1 encrypt|decrypt входной_файл выходной_файл DES|DEAL MODE PADDING
```

Алгоритм, режим и набивка обязательны. Для расшифрования укажи те же значения, что при шифровании; без них программа остановится до чтения файла.

```sh
./lab1 encrypt march.jpg march.jpg.enc DES CBC PKCS7
./lab1 decrypt march.jpg.enc march-recovered.jpg DES CBC PKCS7
./lab1 encrypt song.mp3 song.mp3.enc DEAL CTR PKCS7
./lab1 decrypt song.mp3.enc song-recovered.mp3 DEAL CTR PKCS7
```

Вместо `march.jpg` или `song.mp3` можно указать текстовый, аудио-, графический, видеофайл или любой другой файл. Режимы: `ECB`, `CBC`, `PCBC`, `CFB`, `OFB`, `CTR`, `RandomDelta`. Набивки: `Zeros`, `ANSI_X923`, `PKCS7`, `ISO10126`. Для CFB, OFB, CTR и RandomDelta набивка не используется.

Ключи и IV для файловой командной строки заданы в коде. Они не сохраняются в зашифрованном файле, поэтому при расшифровании нужно выбрать те же алгоритм и режим. В файловом варианте `RandomDelta` использует фиксированный шаг для воспроизводимой расшифровки; демонстрация без аргументов генерирует псевдослучайные IV и шаг.

## Устройство реализации

- `permuteBits` — перестановка битов с выбором направления нумерации.
- `IKeyExpansion`, `IRoundTransform`, `ISymmetricCipher` — интерфейсы расширения ключа, раундового преобразования и блочного шифра.
- `FeistelCipher` — повторно используемая сеть Фейстеля.
- `DESCipher` и `DEALCipher` — DES и DEAL на общей сети Фейстеля.
- `CipherContext` — режимы, набивка, обработка буферов и файлов.
- Методы `encryptAsync`, `decryptAsync` и варианты для файлов запускают операцию асинхронно и возвращают `std::future`. Обработка блоков внутри операции последовательная.

Файлы целиком загружаются в память. Набивка Zeros не позволяет отличить исходные конечные нулевые байты от добавленных.
