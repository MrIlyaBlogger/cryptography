# Лабораторная работа № 1 по основам криптографии

Реализация на C++17 находится в `lab1.cpp`. Готовые криптографические библиотеки не используются.

## Сборка и запуск

```sh
g++ -std=c++17 -O2 -pthread lab1.cpp -o lab1
./lab1
```

Без аргументов программа показывает демонстрацию шифрования и обратного преобразования данных для DES и DEAL во всех поддерживаемых режимах.

Файлы можно шифровать и дешифровать так:

```sh
./lab1 encrypt input.bin encrypted.bin DES
./lab1 decrypt encrypted.bin recovered.bin DES
./lab1 encrypt input.bin encrypted.bin DEAL
./lab1 decrypt encrypted.bin recovered.bin DEAL
```

Ключи и IV для файловой демонстрации заданы в `main`. При расшифровании нужно использовать ту же пару ключ/IV. Для DES допустим ключ длиной 8 байт; для DEAL — 16, 24 или 32 байта.

## Состав

- `permuteBits` — перестановка битов с выбором порядка битов в байте и нумерации с нуля или единицы.
- `IKeyExpansion`, `IRoundTransform`, `ISymmetricCipher` — интерфейсы расширения ключа, раундового преобразования и блочного шифра.
- `FeistelCipher` — повторно используемая сеть Фейстеля.
- `DESCipher` и `DEALCipher` — DES и DEAL на общей сети Фейстеля.
- `CipherContext` — ECB, CBC, PCBC, CFB, OFB, CTR и RandomDelta; набивки Zeros, ANSI X.923, PKCS7 и ISO 10126; асинхронные операции с буферами и файлами.

Для `RandomDelta` требуется передать начальное значение счётчика через `iv` и ненулевой шаг счётчика через `extraParameters` (массив байтов длиной в размер блока). Для каждого шифрования выбирайте новые случайные IV и шаг и сохраняйте их вместе с шифротекстом; при расшифровании передайте те же значения. Для CFB, OFB, CTR и RandomDelta данные обрабатываются без набивки. Набивка Zeros не позволяет отличить исходные конечные нулевые байты от добавленных.
